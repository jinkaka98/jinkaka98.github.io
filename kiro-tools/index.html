How it works

Enter your 9Router URL (e.g. http://localhost:20128 or a Tailscale IP). Works from any device.

If direct connection fails due to browser CORS, we automatically retry via a public CORS relay. For maximum privacy, use Direct mode or access this tool at http://localhost:20128/kiro.html inside 9Router's own network.

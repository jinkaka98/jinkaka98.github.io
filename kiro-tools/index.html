Setup Pertama Kali

Kamu perlu menjalankan file setup sekali saja agar Kiro Tools bisa terhubung ke 9Router kamu.

1
Download file setup
2
Buka file yang sudah di-download
Double-click file setup-kiro-tools.bat di folder Downloads kamu. Kalau muncul peringatan Windows, klik "More info" lalu "Run anyway".
3
Restart 9Router
Tutup 9Router (Ctrl+C di terminal), lalu jalankan ulang dengan ketik 9router
4
Kembali ke sini
Refresh halaman ini — seharusnya langsung terhubung dan siap dipakai.

Setup ini cuma perlu dilakukan 1x saja. Setelah itu, halaman ini langsung bisa dipakai kapanpun.

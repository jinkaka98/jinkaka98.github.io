Setup Pertama Kali

Jalankan file setup sekali saja agar Kiro Tools bisa terhubung ke 9Router kamu.

1
Download file setup
2
Double-click file tersebut
Buka setup-kiro-tools.bat di folder Downloads. Kalau muncul peringatan Windows, klik "More info" → "Run anyway".
3
Restart 9Router
Tutup 9Router (Ctrl+C), jalankan ulang: 9router
4
Kembali ke sini
Refresh halaman ini — langsung terhubung.

Untuk 9Router yang di-install di VPS/server dan diakses via domain (misal https://router2.alpakyros.com), jalankan perintah berikut di server via SSH:

Jika install via NPM:
curl -sL https://jinkaka98.github.io/kiro-tools/patch.js | node -
File patch.js akan otomatis cari lokasi 9Router di server.
Jika install via Docker:
docker exec -it 9router sh -c "curl -sL https://jinkaka98.github.io/kiro-tools/patch.js | node -"
Jalankan di dalam container 9Router.
Setelah patch, restart:
NPM: pm2 restart 9router atau tutup & jalankan ulang 9router
Docker: docker restart 9router
Lalu kembali ke sini
Masukkan URL domain kamu di kolom "9Router URL" di atas (misal https://router2.alpakyros.com), klik Connect, lalu refresh.

Setup cuma 1x. Setelah itu halaman ini langsung bisa dipakai kapanpun.
